# パラメータ設計

基準となるプリセットは `src/config/defaults.ts` に定義されています。全プリセットは `seed` に依存した決定論的な再現性を持ちます。

## プリセット概要

| プリセット     | 用途          | 特徴                                                              |
| -------------- | ------------- | ----------------------------------------------------------------- |
| `defaults`     | 初回 1v1 表示 | 対称構成。射程 9px・クールダウン 0.45s の基本バランス調整に使用。 |
| `defaults3v3`  | 複数体検証    | 3v3。役割の異なる 3 体で間合いと集団戦のテンポを確認。            |
| `aiDemoConfig` | AI デモ       | `aggressive` vs `defensive` の挙動比較。UI 切り替えでも利用。     |
| `mixedAI3v3`   | AI 相互作用   | 3 種類の AI を混在。衝突回避とターゲット選択の検証向け。          |

## 共通パラメータ

| 名称          | 既定値                                 | 説明                                       |
| ------------- | -------------------------------------- | ------------------------------------------ |
| `arenaRadius` | 220                                    | アリーナ半径。描画スケールと一致。         |
| `tickRate`    | 60                                     | シミュレーション固定フレームレート (Hz)。  |
| `hpMax`       | 80〜120                                | 体力。1v1 では 120 を基準。                |
| `atk`         | 8〜12                                  | 1 攻撃あたりのダメージ量。                 |
| `range`       | 8〜10                                  | 攻撃射程（px）。射程サークルと同期。       |
| `speed`       | 60〜90                                 | 移動速度（px/s）。                         |
| `cooldown`    | 0.4〜0.6                               | 攻撃間隔（秒）。                           |
| `aiType`      | `nearest` / `aggressive` / `defensive` | 戦略 ID。未指定時は `nearest` を自動適用。 |

## 調整のヒント

- `speed * cooldown ≈ range` を目安にすると近接戦の膠着を避けやすい。値が小さすぎると接敵できず、大きすぎると攻撃過剰になる。
- HP と攻撃力を同率で調整するとバトル時間を保ちやすい。瞬間火力だけ調整したい場合は `atk` を単独変更する。
- 3v3 以上で初期位置が重なる場合は `arenaRadius` を 240 以上に広げると HUD と射程の視認性が確保しやすい。
- `tickRate` を変更する際は `playbackController` の `maxDelta` も揃えて、描画ループとの乖離を防ぐ。

## 今後の拡張候補

- 攻撃半径 (`attackRadius`) を導入し、照準サークルとヒット判定を分離する。
- 回避行動 (`dash`) や速度バフを AI 戦略に組み込み、間合い制御を高度化する。
- 命中・クリティカル等の確率要素をログに記録しつつ決定論を保つ仕組みを検討する。
