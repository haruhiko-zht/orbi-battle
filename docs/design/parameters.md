# パラメータ設計

`src/config/defaults.ts` に定義されたプリセットを基準に調整します。全プリセットは決定論（seed 依存）で再現可能です。

## プリセット一覧

| プリセット     | 用途              | 特徴                                                                      |
| -------------- | ----------------- | ------------------------------------------------------------------------- |
| `defaults`     | 1v1 初期表示      | 対称なミラー構成。射程 9px、1 体同士のバランス調整に利用。                |
| `defaults3v3`  | 多人数検証        | 3v3 編成。役割の異なる 3 体を配置し、集団戦の間隔とクールダウンを確認。   |
| `aiDemoConfig` | AI デモ           | Aggressive vs Defensive の挙動比較用。AI 切り替え UI の動作確認にも使用。 |
| `mixedAI3v3`   | AI ごとの相互作用 | 3 種類の AI を混在させた 3v3。衝突回避やターゲット選択の検証向け。        |

## 共通パラメータ

| 名称          | 既定値                                 | 説明                                        |
| ------------- | -------------------------------------- | ------------------------------------------- |
| `arenaRadius` | 220                                    | アリーナ半径（描画スケールと一致）。        |
| `tickRate`    | 60                                     | シミュレーションの固定フレームレート (Hz)。 |
| `hpMax`       | 80〜120                                | ファイター体力。1v1 は 120 を基準。         |
| `atk`         | 8〜12                                  | 1 発あたりのダメージ。                      |
| `range`       | 8〜10                                  | 攻撃射程（px）。射程サークル表示とも同期。  |
| `speed`       | 60〜90                                 | 移動速度（px/s）。                          |
| `cooldown`    | 0.4〜0.6                               | 攻撃間隔（秒）。                            |
| `aiType`      | `nearest` / `aggressive` / `defensive` | AI 戦略。未指定時は `nearest`。             |

## 調整の目安

- `speed * cooldown ≈ range` が近接戦の安定領域。値が小さいと膠着し、大きいと行動過多になる。
- HP と攻撃力を同じ比率で変更すると試合時間が保たれ、バーストだけ調整したい場合は `atk` の単独変更を推奨。
- 複数チーム構成では、`arenaRadius` を 240 以上にすると開始位置が重ならず、HP バーの視認性も保てる。
- `tickRate` を変更する場合は `playbackController` の `maxDelta` とセットで見直し、描画との乖離を避ける。

## 拡張候補

- 攻撃半径 (`attackRadius`) を別パラメータ化し、照準サークルとヒット判定を分離する。
- 回避行動 (`dash`) や移動バフ効果を AI 戦略に組み込む。
- 命中率・クリティカル率を導入し、決定論を保ったまま確率ロジックをログへ記録する。
