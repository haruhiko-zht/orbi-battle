# シミュレーション仕様

## 構造

- **Fighter**: 行動主体（味方/敵）
- **BattleState**: 双方の位置・HP・勝敗状態（1 フレーム分）
- **Engine**: 時間更新・勝敗判定を制御
- **BattleSim**: 事前計算されたログを再生するリプレイヤー
- **BattleLog**: バトル全体の記録（設定 + 全フレーム）

## チーム構成

- 常に味方チームと敵チームの **合計 2 チーム**のみを扱う
- 追加の陣営（観戦者・中立など）は現行仕様ではサポートしない

## 行動ルール

1. 距離 > range → 敵に向かって移動
2. 距離 ≤ range → cooldown=0 なら攻撃
3. HP ≤ 0 → 敗北判定

## パラメータ

| 名称     | 意味     | 単位    |
| -------- | -------- | ------- |
| hpMax    | 最大 HP  | -       |
| atk      | 攻撃力   | HP 単位 |
| range    | 攻撃射程 | px      |
| speed    | 移動速度 | px/s    |
| cooldown | 攻撃間隔 | 秒      |

## AI レジストリ

- `src/sim/ai/types.ts` の `AI_DEFINITIONS` に AI タイプ名と表示ラベルを一元管理
- `AI_TYPES` / `AI_OPTIONS` は上記定義から自動生成され、シミュレーション層・UI 層双方で共有
- 追加手順:
  1. `AI_DEFINITIONS` に `{ 新タイプ: { label: "表示名" } }` を追記
  2. `src/sim/ai/index.ts` の `aiFactories` にファクトリ関数を実装
  3. 必要に応じて UI（デバッグパネル等）で `AI_OPTIONS` を参照
- これにより追加・削除の際に複数ファイルを横断する必要がなく、拡張ミスを防げる

## 決定論

- `seed` に基づく乱数生成 (Mulberry32)
- 同じパラメータ + seed で同結果
- **事前シミュレーション方式**: バトル開始時に全フレームを計算してログに記録
  - リプレイ可能
  - サーバー送信可能
  - デバッグしやすい
