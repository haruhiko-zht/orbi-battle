# 描画仕様 (Phaser)

## 要素一覧

| 要素     | 種類     | 内容                                |
| -------- | -------- | ----------------------------------- |
| Arena    | Arc      | 円形フィールド (半径 `arenaRadius`) |
| Fighter  | Arc      | A: 緑 / B: 赤                       |
| HP バー  | Graphics | 背景 + 残量バー                     |
| HP 数値  | Text     | バー中央に重ねて表示                |
| 結果表示 | Text     | `WINNER: A/B`                       |

## レイアウト

- 中心座標: 画面中央 (cx, cy)
- HP バー:
  - A: 画面下部 - 2 行目
  - B: 画面下部 - 1 行目
- HP テキスト: バー中央にセンタリング (水平+垂直)
