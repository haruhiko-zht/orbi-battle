# 描画仕様 (Phaser)

## 要素一覧

| 要素     | 種類     | 内容                                  |
| -------- | -------- | ------------------------------------- |
| Arena    | Arc      | 円形フィールド (半径 `arenaRadius`)   |
| Fighter  | Arc      | チームカラーパレットから自動割り当て  |
| HP バー  | Graphics | 背景 + 残量バー（チーム色で塗り分け） |
| HP 数値  | Text     | バー中央に重ねて表示                  |
| 結果表示 | Text     | `WINNER: A/B`                         |

## レイアウト

- 中心座標: 画面中央 (cx, cy)
- HP バー（2 列レイアウト）:
  - 味方（`teams[0]`）: 画面右下から上方向に積み上げ
  - 敵（`teams[1]`）: 画面左下から上方向に積み上げ
- 2 チーム以外の構成を受け取った場合は警告を出し、旧来の単一列レイアウトにフォールバック
- HP テキスト: バー中央にセンタリング (水平+垂直)
