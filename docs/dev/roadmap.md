## 注力中（〜10月下旬）

- **回避行動のプロトタイプ** — 攻撃射程サークルを利用し、近接 AI が差し込み時にヒット判定を避ける簡易ロジックを検証。
- **AI 選択 UI** — デバッグパネルから `nearest` / `aggressive` / `defensive` を即時切り替え可能にする。
- **HP UI 微調整** — 3v3 以上で HP バーが重ならないよう余白とフォントサイズを見直す。

## 次の候補（着手順未定）

- **イベントフック整備** — `BattleRuntimeController` でヒット・死亡イベントをフックし、演出強化へ繋げる。
- **プリセット整理** — `defaults3v3` と `mixedAI3v3` の開始位置を `arenaRadius` と連動させ、初期重なりを解消。
